# Soplang tutorial

Get started writing Soplang programs.

## Hello, world

```sop
qor("Salaan, Adduunka!")
```

Run with: `soplang hello.sop`

## Variables and types

Use `door` for dynamic typing or type keywords for static typing:

```sop
door magac = "Sharafdin"
abn tirada = 25
qor(magac + ", " + tirada)
```

## Functions

```sop
hawl salaam(qof) {
    celi "Salaan, " + qof + "!"
}
qor(salaam("Maxamed"))
```
