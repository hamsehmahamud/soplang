# Soplang expressions

This document describes expressions and operator usage in Soplang.

## Overview

Expressions produce values. They include:

- **Literals** — numbers, strings, `run`/`been`, `aaw`
- **Variables** — identifier names
- **Binary operators** — arithmetic (`+`, `-`, `*`, `/`), comparison (`==`, `!=`, `>`, `<`, etc.), logical (`iyo`, `ama`)
- **Unary operators** — `ma` (not), `-`
- **Call expressions** — `magac(...)`, `x.qeybi(...)`
- **Subscript** — `liis[0]`, `qoraal[1:4]`

For keyword and syntax reference, see [keywords.md](keywords.md). For formal grammar, see [grammar.md](grammar.md).
